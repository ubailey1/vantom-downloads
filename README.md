# VANTOM downloads

Download host for **VANTOM**, the four-layer dynamic synthesizer by [The Indie Scientist](https://theindiescientist.com/products/vantom/).

Each test build is published as a [release](https://github.com/ubailey1/vantom-downloads/releases) with a Windows installer and a macOS package. For install instructions, system requirements and the Logic Pro guide, see the [VANTOM page](https://theindiescientist.com/products/vantom/#download).

The latest build is always at:

- Windows: https://github.com/ubailey1/vantom-downloads/releases/latest
- macOS: https://github.com/ubailey1/vantom-downloads/releases/latest

Test builds are provided as-is for evaluation. See the [Terms of Service](https://theindiescientist.com/legal/terms/).
